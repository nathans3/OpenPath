# OpenPath logo

OpenPath's glowing circle, with a path of steps winding up to a ring, like the pointer that shows what to click. One clear step at a time.

| File | Use |
|---|---|
| `openpath-logo.png` / `.svg` | Logo with the name, on light backgrounds |
| `openpath-logo-dark.png` / `.svg` | Logo with the name, on dark backgrounds |
| `openpath-icon.png` / `.svg` | App icon (rounded square), 1024 × 1024 |
| `openpath-mark.png` / `.svg` | The circle alone, transparent background |

Colors: sea glass `#5fd3c4` / `#7fe0d2`, periwinkle `#5a6fe8`, ink `#16202a`, path blue `#1f6f8b`, navy `#0f1b2a`.

The PNGs are the reference artwork. To re-render after editing an SVG:

```bash
npx electron brand/render.js '[["brand/openpath-logo.svg","brand/openpath-logo.png",1400,400]]'
```
